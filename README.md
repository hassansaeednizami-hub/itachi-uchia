# Itachi Uchiha Anime Website

This is a modern Itachi Uchiha anime fan website inspired by the Naruto universe.

The website has a dark black and red theme that represents Itachi's mysterious and powerful character. It contains information about his abilities, Uchiha Clan, Akatsuki, story, and personality.

## Features

- Itachi Uchiha Hero Section
- Sharingan Information
- Mangekyou Sharingan Information
- Akatsuki Section
- About Itachi Section
- Character Stats
- Itachi Gallery
- Contact Section
- Hover Effects
- Smooth Scrolling
- CSS Animations
- Responsive Design
- Custom Scrollbar

## Technologies Used

HTML5
CSS3
Flexbox
CSS Grid
CSS Animations
Responsive Design

## Website Sections

Home:
Introduces Itachi Uchiha as the legendary shinobi.

Characters:
Shows important abilities and characteristics related to Itachi.

About:
Provides information about Itachi, his Uchiha Clan, rank, and Akatsuki team.

Gallery:
Displays different images of Itachi with hover effects.

Contact:
Contains contact information and Hidden Leaf Village details.

## Project Goal

The main goal of this project was to practice HTML and CSS by creating a complete anime-themed website. I practiced layouts, cards, images, buttons, hover effects, animations, Flexbox, Grid, and responsive design.
